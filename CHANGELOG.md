# Changelog

All notable changes to this plugin will be documented here.

## 1.0.0 — initial release

- Added the `receipts` MCP server pointing at the hosted Receipts endpoint (`https://receipts.77systems.ai/mcp`).
- Auth uses OAuth with dynamic client registration. Sign in with Google or an emailed link; there is no API key or client ID to configure.
- Logo: the Receipts app icon from 77systems.
